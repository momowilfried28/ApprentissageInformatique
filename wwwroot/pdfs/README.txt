Dossier pour les fichiers PDF des modules
==========================================

Structure :
- module1/module1.pdf
- module2/module2.pdf
- module3/module3.pdf
- module4/module4.pdf

Pour ajouter un PDF pour un module :
1. Placez le fichier PDF dans le dossier correspondant (module1, module2, etc.)
2. Nommez-le selon le format : module1.pdf, module2.pdf, etc.
3. Le bouton "Voir le PDF" ou "En savoir plus" ouvrira automatiquement le PDF dans un nouvel onglet

Le PDF sera accessible via l'URL : /pdfs/moduleX/moduleX.pdf
